📔 FitLog Product Handbook

ຄູ່ມືແນະນຳຜະລິດຕະພັນ ແລະ ການວິເຄາະລາຍລະອຽດແຕ່ລະຟັງຊັນ

🔥 Product Presentation Spec

🎯 ສ່ວນທີ 1: ການແນະນຳແອັບພລິເຄຊັນ (App Introduction & Value Proposition)

1.1 FitLog ແມ່ນຫຍັງ?

FitLog ບໍ່ແມ່ນພຽງແຕ່ແອັບບັນທຶກການອອກກຳລັງກາຍທົ່ວໄປ, ແຕ່ມັນຄື "ຄູ່ຫູສຸຂະພາບສ່ວນຕົວ (Personal Fitness Companion)" ທີ່ເຮັດວຽກແບບ Offline 100% ເພື່ອຄວາມເປັນສ່ວນຕົວຂອງຂໍ້ມູນ. ແອັບນີ້ຖືກພັດທະນາຂຶ້ນເພື່ອຕອບໂຈດຄົນຮັກສຸຂະພາບທີ່ຕ້ອງການຄວາມງ່າຍດາຍ ແຕ່ໄດ້ຮັບຂໍ້ມູນການວິເຄາະທີ່ຄົບຖ້ວນ ທັງດ້ານການອອກກຳລັງກາຍ ແລະ ໂພຊະນາການ.

1.2 ບັນຫາທີ່ແອັບເຂົ້າມາແກ້ໄຂ (Problem-Solution Fit)

  • ບັນຫາການຫຼົງລືມ ຫຼື ຂາດແຮງຈູງໃຈ: ລະບົບ Streak 🔥 ຈະຄອຍກະຕຸ້ນໃຫ້ຜູ້ໃຊ້ອອກກຳລັງກາຍໃຫ້ບັນລຸເປົ້າໝາຍທຸກໆມື້.
  • ຄວາມຫຍຸ້ງຍາກໃນການຄຳນວນ Macronutrients: ແອັບມີລະບົບ Smart Profile Calculator 🥗 ທີ່ຊ່ວຍຄຳນວນປະລິມານການກິນແປ້ງ, ໂປຣຕີນ ແລະ ໄຂມັນໃຫ້ອັດຕະໂນມັດ ໂດຍບໍ່ຕ້ອງເພິ່ງພາຜູ້ຊ່ຽວຊານ.
  • ການບໍ່ຮູ້ຄວາມກ້າວໜ້າຂອງຕົນເອງ: ລະບົບ Interactive Graphs 📊 ປ່ຽນຂໍ້ມູນຕົວເລກທີ່ໜ້າເບື່ອໃຫ້ກາຍເປັນກຣາຟທີ່ເບິ່ງງ່າຍ ແລະ ສວຍງາມ.

🔄 ສ່ວນທີ 2: ຂັ້ນຕອນການໃຊ້ງານລະອຽດ (Step-by-Step User Guide)

ການໃຊ້ງານ FitLog ຖືກອອກແບບມາໃຫ້ມີ User Journey (ເສັ້ນທາງການໃຊ້ງານ) ທີ່ສັ້ນ ແລະ ງ່າຍດາຍທີ່ສຸດ ໂດຍແບ່ງອອກເປັນ 4 ຂັ້ນຕອນຫຼັກ:

1

ການເລີ່ມຕົ້ນສ້າງໂປຣໄຟລ໌ສຸຂະພາບ (First-Time Onboarding)

ໃນການໃຊ້ງານຄັ້ງທຳອິດ, ແອັບຈະພາຜູ້ໃຊ້ໄປຍັງໜ້າ Profile Setup ທັນທີ. ປ້ອນຂໍ້ມູນສ່ວນຕົວ: ເພດ, ອາຍຸ, ນ້ຳໜັກ, ສ່ວນສູງ, ລະດັບກິດຈະກຳ ແລະ ເປົ້າໝາຍ. ລະບົບຈະຄຳນວນຄ່າ BMR, TDEE ແລະ Macronutrients ທີ່ເໝາະສົມໃຫ້ທັນທີ.

2

ການອອກກຳລັງກາຍ ແລະ ການບັນທຶກ (Workout & Logging Flow)

ຜູ້ໃຊ້ສາມາດບັນທຶກໄດ້ 2 ແບບ: ແບບຈັບເວລາຕົວຈິງ (Active Timer) ໂດຍກົດໄປແຖບ Timer ແລ້ວກົດ Start/Pause ເມື່ອສຳເລັດກົດ Save ລະບົບຈະສົ່ງເວລາໄປໜ້າ Add ອັດຕະໂນມັດ, ຫຼື ແບບບັນທຶກດ້ວຍມື (Manual Log) ໂດຍກົດປຸ່ມ FAB ➕ ຢູ່ໜ້າໃດກໍໄດ້ແລ້ວກອກຂໍ້ມູນດ້ວຍຕົນເອງ.

3

ການຕິດຕາມຜົນງານປະຈຳວັນ (Daily Monitoring)

ກັບມາທີ່ໜ້າ Home Dashboard 🏠 ເພື່ອກວດເບິ່ງ Daily Streak (ມື້ນີ້ເຮົາອອກກຳລັງກາຍບັນລຸເປົ້າໝາຍນາທີຫຼືຍັງ?), Nutrition Intake (ມື້ນີ້ເຮົາຄວນກິນອາຫານເທົ່າໃດ?), ແລະ Recent Workouts ຫຼ້າສຸດ.

4

ການວິເຄາະ ແລະ ປັບປຸງເປົ້າໝາຍ (Analysis & Settings)

ກົດເຂົ້າແຖບ Statistics 📊 ເພື່ອເບິ່ງແນວໂນ້ມກຣາຟ 7 ມື້ ຫຼື 30 ມື້ຜ່ານມາ ແລະ ກົດເຂົ້າແຖບ Settings ⚙️ ເພື່ອປ່ຽນແປງເປົ້າໝາຍ ຫຼື ເປີດໂໝດມືດ (Dark Mode) ເພື່ອຄວາມສະບາຍຕາ.

🧩 ສ່ວນທີ 3: ການວິເຄາະຄວາມສຳຄັນຂອງແຕ່ລະຟັງຊັນ (Feature Value Matrix)

ຕາຕະລາງລຸ່ມນີ້ຈະອະທິບາຍເຖິງໜ້າທີ່, ຄວາມສຳຄັນ, ແລະ ຜົນກະທົບຕໍ່ຜູ້ໃຊ້ (UX Impact) ຂອງແຕ່ລະຟັງຊັນໃນແອັບ FitLog:

ຟັງຊັນ (Feature) ລະດັບຄວາມສຳຄັນ ຜົນກະທົບ ແລະ ຄຸນຄ່າຕໍ່ຜູ້ໃຊ້ (UX Value)
1. ຈັດການຂໍ້ມູນອອກກຳລັງກາຍ (Workout CRUD) 🔴 ສູງທີ່ສຸດ ຫຼັກຂອງແອັບ: ຊ່ວຍໃຫ້ຜູ້ໃຊ້ຈັດການ, ແກ້ໄຂ, ຄົ້ນຫາ ແລະ ກັ່ນຕອງປະຫວັດການອອກກຳລັງກາຍທັງໝົດໄດ້ຢ່າງເປັນລະບົບ.
2. ລະບົບໂປຣໄຟລ໌ສຸຂະພາບ (Nutrition & BMR Calculator) 🔴 ສູງ ສ້າງຄວາມຫຼູຫຼາ: ຄຳນວນແຄລໍຣີ ແລະ Macronutrients ອັດຕະໂນມັດ ໂດຍບໍ່ຕ້ອງເພິ່ງພາ Coach ສ່ວນຕົວ.
3. ໜ້າຫຼັກສະຫຼຸບຜົນ (Home Dashboard) 🔴 ສູງ First Impression: ສະແດງຂໍ້ມູນສຳຄັນທັງໝົດ (Streak, Macronutrients, Stats) ໃນໜ້າດຽວ ຫຼຸດຜ່ອນການກົດຫຼາຍຂັ້ນຕອນ.
4. ກຣາຟສະຖິຕິ (Interactive Statistics) 🟡 ກາງ-ສູງ ສ້າງແຮງຈູງໃຈ: ສະແດງແນວໂນ້ມ ແລະ ສັດສ່ວນກິດຈະກຳຜ່ານກຣາຟຫຼາກຫຼາຍຮູບແບບ ເຮັດໃຫ້ເຫັນພຶດຕິກຳສຸຂະພາບຊັດເຈນ.
5. ຕົວຈັບເວລາ (Stopwatch Timer) 🟡 ກາງ Seamless Flow: ຈັບເວລາຈິງ ແລະ ສົ່ງຄ່າເວລາໄປຟອມບັນທຶກທັນທີ ໂດຍບໍ່ຕ້ອງພິມເອງ.
6. ລະບົບ Streak 🔥 🟡 ກາງ ສ້າງນິໄສ: ໃຊ້ Gamification ກະຕຸ້ນໃຫ້ຜູ້ໃຊ້ອອກກຳລັງກາຍທຸກໆມື້ ເພື່ອຮັກສາ Streak ບໍ່ໃຫ້ເປັນ 0.
7. ໂໝດມືດ (Dark Mode) 🟢 ຕ່ຳ-ກາງ UX Premium: ຮັກສາສາຍຕາໃນການອ່ານຕອນກາງຄືນ ແລະ ເພີ່ມຄວາມຫຼູຫຼາສວຍງາມ.
📝 ຂໍ້ມູນເພີ່ມເຕີມ: ແບບທີ 2 (Product Handbook) ນີ້ ເໝາະສຳລັບການນຳໃຊ້ໃນການສະເໜີຈຸດເດັ່ນຂອງແອັບ (Pitching) ໃຫ້ກັບນັກລົງທຶນ ຫຼື ຜູ້ໃຊ້ທົ່ວໄປ ເພາະເນັ້ນເຫັນ **ຄຸນຄ່າ (Value)** ແລະ **ຜົນປະໂຫຍດ** ທີ່ຜູ້ໃຊ້ຈະໄດ້ຮັບຢ່າງຊັດເຈນ ໂດຍຫຼີກລ່ຽງຄຳສັບທາງເຕັກນິກທີ່ເຂົ້າໃຈຍາກ.
